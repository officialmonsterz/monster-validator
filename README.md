# 🚀 MONSTER VALIDATOR

Real-time phone number validation tool built for speed, simplicity, and live results.

Supports:
- ✅ Twilio Lookup API
- ✅ Numverify API
- ✅ TXT Export
- ✅ JSON Export
- ✅ SQLite Storage
- ✅ Windows Compatible
- ✅ Async High-Speed Validation
- ✅ Beginner Friendly CLI

Created by: monsterdrak  
GitHub: https://github.com/officialmonsterz

# 📸 Features

## ✅ Real-Time Validation
Watch results appear LIVE while numbers are being checked.

## ✅ Multi Provider Support
Supports:
- Twilio Lookup API
- Numverify API

## ✅ TXT Output
Clean and readable TXT results.

## ✅ JSON Backup
Automatic JSON export for developers and automation.

## ✅ SQLite Database
Stores validated numbers locally.

## ✅ Mobile Filtering
Optional filter for mobile numbers only.

## ✅ Beginner Friendly
Simple menu system with no coding knowledge needed.

## ✅ Windows Ready
Includes Windows asyncio compatibility fix.
